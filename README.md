# simagora

Financial instrument backtesting simulator.

Documentation is split into the following sections:

- [Overview](docs/overview.md) — what the simulator does and its conceptual design.
- [Layout](docs/layout.md) — repo/package structure, module by module.
- [Strategies](docs/strategies.md) — the registered trading strategies and how to select them.
- [Multi-instrument support](docs/multi-instrument.md) — how strategies trade across a universe of instruments.
- [Position closing](docs/position-closing.md) — the order in which a position can close.
- [Setup](docs/setup.md) — installing the package before running anything.
- [Testing](docs/testing.md) — running the test suite.
- [Data](docs/data.md) — where market data is read from.
- [Running](docs/running.md) — how to construct and run a simulation.
